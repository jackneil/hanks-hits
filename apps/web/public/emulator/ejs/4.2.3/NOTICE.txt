Hank's Hits: notice for the Retro Arcade emulator (EmulatorJS 4.2.3)
Last updated: 2026-09-29

Retro Arcade on this site plays games in your browser. It uses EmulatorJS
and emulator cores. This site sends these files to your browser. This notice
tells you what each part is and what its license is. It also tells you where
to get its license text and its source code.

All paths in this notice are in the folder /emulator/ejs/4.2.3/ on this site.
For example, source/snes9x-6ca2343e5f3b.tar.gz is at
/emulator/ejs/4.2.3/source/snes9x-6ca2343e5f3b.tar.gz.

Hank's Hits is free. It has no ads and no payments.


A. We did not change the files
------------------------------

Each file that we send is the same as the file in the official EmulatorJS
4.2.3 release:
  https://github.com/EmulatorJS/EmulatorJS/releases/download/v4.2.3/4.2.3.7z
  SHA-256 of the release file:
  07d451bc06fa3ad04ab30d9b94eb63ac34ad0babee52d60357b002bde8f3850b

manifest.json in this folder gives the size and the SHA-256 of each file.
It also gives the size, the SHA-256 and the download URL of each source
archive and each license text.


B. How to get the source code
-----------------------------

The folder source/ holds the source code of the files that we send. You can
download it from this site at no cost. You do not need an account. We keep
the source code here for as long as we send the files.

Each .tar.gz archive in source/ is an unchanged copy of the archive that
GitHub makes for one git commit. The name of the archive has the first 12
characters of the commit ID. The first header in the archive holds the full
commit ID. manifest.json gives the commit ID and the URL of each archive.

Each core file (cores/*.data) is a 7z archive. It holds one WebAssembly
program, the JavaScript code that loads it, core.json, build.json and, for
most cores, license.txt. The WebAssembly program is RetroArch and one
emulator core, compiled together. Thus the source code of a core file is the
source code of the core, of RetroArch (part 2) and of the build scripts
(part 3).

4. The emulator cores

   Each core has two files: cores/<core>-wasm.data (WebGL 2) and
   cores/<core>-legacy-wasm.data (WebGL 1). Both come from the same commit.
   cores/reports/<core>.json gives the build time.
   How we know each commit: the Makefile of each core puts the short git
   commit ID into the core (git rev-parse --short HEAD). We give the text
   that each core contains below. GitHub gives the full commit ID for it.

7. extract7z.js and extractzip.js (in compression/)

   What they do here: they open 7z and ZIP files. Each core file is a 7z
   archive, so extract7z.js runs for each game.
   Source code: we could not find it. EmulatorJS has had these two files
   since its first commit (12 May 2021). EmulatorJS does not publish their
   source code. The EmulatorJS source archive holds the same two files.
   Their text shows a 7z decoder, a ZIP reader and the Emscripten runtime
   with the musl C library.
   License: not known. EmulatorJS gives them with its GPL-3.0 release.
