1. FFmpeg (libavcodec and libavutil), version 8.1.3
---------------------------------------------------

License: GNU Lesser General Public License, version 2.1 or later
         (LGPL-2.1-or-later). Full text: /licenses/LGPL-2.1.txt
Copyright (c) 2000-2026 the FFmpeg developers.
Some FFmpeg files have MIT, BSD or ISC style licenses. Their notices are in
the source code file below.

What it does here: FFmpeg encodes the game sound of a clip as AAC audio. The
site uses it only on browsers that cannot encode AAC audio themselves.

Shipped file: /clips/aac/ffmpeg-aac-enc.mjs
  This file is a JavaScript module with a WebAssembly program inside. The
  program links libavcodec and libavutil statically. The first lines of the
  file are a license notice (notice.js). The notice names each part in the
  file, its license and the place of this information.
  SHA-256: e2ee0d697dabd45903649b0971d4335bebacf25e53d41b4c8894deffbd7b4c6b

Source code: /licenses/ffmpeg-8.1.3.tar.xz
  SHA-256: 7138d28c96d9d3e3af4ee3d8cad72741f8ffb40da90c1112235dea3ecd3178a3
  This is the unchanged FFmpeg 8.1.3 release tarball from
  https://ffmpeg.org/releases/ffmpeg-8.1.3.tar.xz. The FFmpeg release signing
  key (FCF986EA15E6E293A5644F10B4322F04D67658D8) signs it.
  We did not change the FFmpeg source.

Build files: /licenses/aac-wasm/
  README.md, bridge.c, notice.js, pins.sh, configure-flags.txt,
  emcc-flags.txt, build.sh, container-build.sh, verify.sh, BUILD-INFO.txt and
  ffmpeg-aac-enc.mjs.sha256. BUILD-INFO.txt records the last build and the
  SHA-256 of each build file that it used.

Toolchain: Emscripten 6.0.10, in the Docker image
  emscripten/emsdk:6.0.10@sha256:e077d54e2b8970575ebc4f185ac1de0b95c05f2b266134d4ba27449af7aebf65
  The build runs with no network access. Two clean builds give the same
  module (the same SHA-256).

Configure command (in the FFmpeg source directory):
  emconfigure ./configure '--target-os=none' '--arch=x86_32' '--enable-cross-compile' '--disable-asm' '--disable-x86asm' '--disable-inline-asm' '--disable-programs' '--disable-doc' '--disable-debug' '--disable-all' '--disable-everything' '--disable-autodetect' '--disable-pthreads' '--disable-runtime-cpudetect' '--enable-avcodec' '--enable-encoder=aac' '--cc=emcc' '--cxx=em++' '--ar=emar' '--ranlib=emranlib' '--extra-cflags=-DNDEBUG -Oz -flto -msimd128' '--extra-ldflags=-Oz -flto'

Build command (in the FFmpeg source directory):
  emmake make -j"$(nproc)"
  The -j option sets only the number of parallel jobs. It does not change
  the output.

Link command (in the FFmpeg source directory, with bridge.c and notice.js
copied into it):
  emcc bridge.c libavcodec/libavcodec.a libavutil/libavutil.a -I. '-sMODULARIZE=1' '-sEXPORT_ES6=1' '-sSINGLE_FILE=1' '-sENVIRONMENT=worker' '-sALLOW_MEMORY_GROWTH=1' '-sFILESYSTEM=0' '-sMALLOC=emmalloc' '-sSUPPORT_LONGJMP=0' '-sDYNAMIC_EXECUTION=0' '-sSTACK_SIZE=1048576' '-sEXPORTED_RUNTIME_METHODS=HEAPU8,HEAPF32' '--extern-pre-js=notice.js' '-msimd128' '-flto' '-Oz' -o ffmpeg-aac-enc.mjs

Configure reports: "License: LGPL version 2.1 or later". The build uses no
GPL, nonfree or version 3 option.

Your rights: You can change the FFmpeg source code and build a new module
with the build files above. You can use your changed module in place of ours,
for your own use. You can reverse engineer the module to find and fix
problems in your changes.
